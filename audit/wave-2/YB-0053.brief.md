# YB-0053 · Observer independence: do the inputs that defeat the model's own refusal also defeat the regulator, the Layer 3 observer and a Sentry-shaped filter?

GitHub issue #2 in YobieBenjamin/safety. Wave 2 of the experiment program (docs/20-experiment-program.md).

**Hypothesis.** The failures of the model's refusal, the text-blind regulator (vitals), the Layer 3 observer (request structure) and a Sentry-shaped filter are weakly correlated, so a k-of-n quorum has a joint miss rate materially below the best single monitor. If the failures are strongly correlated, a quorum adds nothing and the chip's value for the knowledge use cases is accountability, not prevention.
